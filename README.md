## DeNICE-AI Portfolio & FAQ-ассистент с RAG (FAISS) и GigaChat

Личный сайт-портфолио и пример проекта FAQ-ассистента для сайта: данные FAQ → RAG через FAISS → backend на FastAPI → виджет чата на фронтенде с использованием моделей GigaChat.

За счёт автоматизации ответов на вопросы клиентов через ИИ-Ассистента, среднее время ответа отдела техподдержки уменьшилось на 25%.

### Структура проекта

- `backend/`
  - `app.py` — FastAPI-сервер, эндпоинт `/chat`, интеграция с GigaChat и поиск по FAISS.
  - `gigachat_client.py` — клиент для работы с API GigaChat (генерация токена, получение эмбеддингов, чат).
  - `build_index.py` — скрипт построения RAG-индекса из FAQ-данных.
  - `rag_index.py` — функции загрузки индекса и поиска похожих ответов.
- `data/`
  - `faqs.json` — пример данных FAQ (вопрос–ответ).
  - `faiss_index.bin`, `faqs_metadata.npy` — будут созданы скриптом `build_index.py`.
- `frontend/`
  - `index.html` — личный сайт портфолио с виджетом чата.
- `requirements.txt` — зависимости Python.

### Подготовка окружения

1. Установите Python 3.10+.
2. В корне проекта создайте файл `.env`:

```env
GIGACHAT_CLIENT_ID=ваш_client_id_от_gigachat
GIGACHAT_CLIENT_SECRET=ваш_client_secret_от_gigachat
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 1. Подготовка данных и построение RAG-индекса (FAISS)

Отредактируйте `data/faqs.json` под свой бизнес (список объектов `{ "question": "...", "answer": "..." }`).

Затем запустите скрипт построения индекса:

```bash
python -m backend.build_index
```

Скрипт:
- посчитает эмбеддинги для текстов `вопрос + ответ` через GigaChat (`Embeddings`);
- создаст FAISS-индекс `faiss_index.bin`;
- сохранит метаданные вопросов/ответов в `faqs_metadata.npy`.

### 2. Запуск backend-сервера

```bash
uvicorn backend.app:app --reload --host 0.0.0.0 --port 8000
```

Эндпоинты:
- `POST /chat` — основной чат с RAG:
  - вход: JSON `{ "message": "текст вопроса", "top_k": 3 }`;
  - выход: `{ "answer": "...", "context": [ { "question": "...", "answer": "..." }, ... ] }`.
- `GET /health` — проверка статуса.

### 3. Frontend (Портфолио и Виджет чата)

Файл `frontend/index.html` содержит:
- Современный лендинг с вашими open-source проектами.
- Плавающую кнопку-виджет в правом нижнем углу.
- Всплывающее окно чата с историей сообщений, индикатором печати и отправкой запросов на `http://localhost:8000/chat`.

Чтобы протестировать локально:

1. Убедитесь, что backend запущен на `http://localhost:8000`.
2. Откройте файл `frontend/index.html` в браузере (двойной клик или через локальный web-server).
3. Нажмите на круглую кнопку с иконкой 💬 и задайте вопрос ассистенту.

### Как это работает (коротко)

1. **Данные FAQ** (`data/faqs.json`) → скрипт `backend/build_index.py` создаёт эмбеддинги через GigaChat и FAISS-индекс.
2. **Запрос пользователя** → backend (`/chat`) получает текст, считает эмбеддинг через GigaChat, ищет ближайшие FAQ в FAISS.
3. **RAG**: найденные FAQ передаются в `system + user` промпт для модели GigaChat.
4. Модель генерирует короткий ответ на русском, используя контекст FAQ, и возвращает его во фронтенд-виджет.
